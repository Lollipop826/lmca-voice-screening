# 长程记忆部署检查清单

## 依赖

- [ ] Python 版本满足项目运行要求
- [ ] 已安装 `requirements.txt` 或 `requirements_windows.txt`
- [ ] 如启用语音模型，额外安装 `requirements-emotion.txt`
- [ ] `memobase==0.0.27` 仅在需要远程镜像时安装并验证
- [ ] 没有把模型缓存或业务数据库写入 C 盘旧目录

## 前端构建

- [ ] `frontend` 已执行 `npm install`
- [ ] `frontend` 执行 `npm run build` 通过，产物位于 `frontend/dist`
- [ ] 开发联调时 Vite `/api` 代理目标指向实际后端地址

## 配置

- [ ] `AUTH_SECRET_KEY` 或持久化认证密钥已配置
- [ ] 已配置登录账号和 API 权限
- [ ] 本地 Memobase 使用根目录 `docker-compose.yml`；已按 [本地 Memobase 部署](memobase-local.md) 配置 `DASHSCOPE_API_KEY`
- [ ] `ACCESS_TOKEN` 与 `MEMOBASE_API_KEY` 相同，且已替换模板默认值
- [ ] 已执行 `docker compose up -d --build memobase-server-db memobase-server-redis memobase-server-api`
- [ ] `http://127.0.0.1:8019/api/v1/healthcheck` 返回成功
- [ ] `EMOTION_USE_TRANSFORMERS` 按机器资源明确设置
- [ ] `USE_MODELSCOPE` 明确设置；未准备模型时保持 `false`
- [ ] 启用模型时，`MODELSCOPE_CACHE` 指向非 C 盘目录
- [ ] SQLite 数据库和音频目录位于可备份磁盘

## 功能验证

- [ ] `python -m pytest -q` 通过
- [ ] `python -m pytest -q tests\test_performance.py` 通过
- [ ] 登录后 `GET /api/memory/{patient_id}` 返回 200
- [ ] `PATCH /api/memory/{patient_id}` 能保存资料和兴趣
- [ ] MMSE 记录能在 `mmse_history` 中保留
- [ ] 新会话能检索旧会话上下文，且上下文带有会话和时间标识
- [ ] `GET /api/memory/{patient_id}/emotion-trajectory` 能读取情绪轨迹
- [ ] 轨迹包含七维分数、效价、唤醒度和主导情绪

## 安全与运维

- [ ] 记忆 API 不绕过现有登录认证
- [ ] 日志不打印 API Key、完整患者隐私或认证 Cookie
- [ ] 已设置 SQLite、配置文件和音频目录的备份策略
- [ ] 已验证备份恢复，而不是只验证备份文件存在
- [ ] 已监控捕获失败、镜像失败、API 5xx 和存储空间
- [ ] 未配置 SoulX 时，已确认本地轮次回退仍可用
