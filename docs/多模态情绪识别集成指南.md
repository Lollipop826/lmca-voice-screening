# 多模态情绪识别集成指南

## 当前边界

文本规则识别是默认路径。Emotion2Vec+ 是可选增强：模型依赖未安装、模型加载失败、音频文件不可读时，结果自动回退为文本七维情绪，不阻塞语音对话服务。

方案中的 82% 准确率、155ms 增量和 10 秒加载时间是目标值，不是本仓库当前已经验证的指标。

## 安装可选依赖

在项目根目录执行：

```powershell
python -m pip install -r requirements-emotion.txt
```

启用模型前设置环境变量。建议将模型缓存放在项目的 `data` 目录或其他非 C 盘目录：

```text
USE_MODELSCOPE=true
EMOTION_USE_GPU=false
EMOTION2VEC_MODEL=iic/emotion2vec_plus_large
MODELSCOPE_CACHE=E:/PROJECT/Emotions/lmca-share/data/modelscope
```

首次使用模型会下载权重。当前机器缺少完整 ModelScope 运行依赖时，保持 `USE_MODELSCOPE=false` 即可继续运行文本路径。

## Python API

```python
from src.tools.emotion import classify_emotion, classify_multimodal

text_scores = classify_emotion("我最近很焦虑")
scores = classify_multimodal(
    text="我最近很焦虑",
    audio_path="patient_audio.wav",
    audio_weight=0.5,
    text_weight=0.3,
    prosody_weight=0.2,
)
```

`classify_multimodal()` 返回固定七维、总和为 1 的字典：`joy`、`sadness`、`anger`、`fear`、`anxiety`、`calm`、`confusion`。没有可用语音模型时，返回值与 `classify_emotion(text)` 一致。

Emotion2Vec+ 的英文/中文标签会归一化到项目七维标签：`happy -> joy`、`sad -> sadness`、`angry/disgusted -> anger`、`fearful -> fear`、`neutral -> calm`、`surprised/other -> confusion`。

## 语音链路

`SpeechTurnProcessor` 在 ASR 成功后：

1. 使用现有 `VoiceAudioStore` 保存一次用户音频。
2. 将 ASR 文本和已保存的音频路径交给 `classify_multimodal()`。
3. 通过 `asyncio.to_thread()` 执行同步模型推理，避免阻塞事件循环。
4. 在 `asr_result` 中保留旧的 `emotion` 字段，并增加 `emotion_label` 和 `emotions`。
5. 完成轮次时把七维结果传给长期记忆。

模型识别失败不会导致 ASR、Agent 或 TTS 失败。

## 长期记忆与轨迹

```python
from src.context_management.emotion_memobase import EmotionMemobase

memory = EmotionMemobase(storage_path="data/voice_server.db")
memory.capture_turn(
    patient_id="patient-001",
    user_message="我最近很担心睡不好。",
    assistant_message="我们先慢慢梳理最近的作息。",
    session_id="session-001",
    emotions=scores,
    audio_path="data/voice_calls/user.wav",
)

trajectory = memory.get_emotion_trajectory("patient-001", limit=100)
```

本地 SQLite 是事实源。每轮会写入已有的记忆快照和逐轮记录，同时写入 `emotion_trajectory`，包含七维分数、效价、唤醒度、主导情绪、会话 ID、触发文本和音频路径。

HTTP 查询接口：

```text
GET /api/memory/{patient_id}/emotion-trajectory?limit=100
```

现有 Memobase 只是可选异步镜像。只有同时配置 `MEMOBASE_PROJECT_URL` 和 `MEMOBASE_API_KEY` 时才会连接 `MemoBaseClient`；未配置时不影响本地读写。

## 验证命令

```powershell
$env:PYTHONPATH = (Get-Location).Path
python -m pytest -q tests/test_multimodal_emotion.py tests/test_emotion_upgrade.py
python tests/benchmark_emotion_models.py
```

没有 `tests/test_audio` 或没有可用模型时，真实声学识别不会被宣称为已通过；可验证的内容是映射、融合、回退和轨迹持久化。

## 相关服务

本功能不依赖 SoulX。SoulX 是独立的可选轮次判断服务，默认地址为 `ws://127.0.0.1:8000/turn`；未启动时主服务应使用本地轮次回退逻辑。
